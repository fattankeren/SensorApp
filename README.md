1.Sensor Gerak Motion
Buat baca gerakan fisik HP. Contohnya Akselerometer (yang kita pakai buat ngegelindingin bola pas HP dimiringkan) dan Giroskop (buat baca putaran/rotasi HP, biasa buat game VR).
2.Sensor Posisi Position
Buat tahu posisi HP di ruangan atau arah mata angin. Contohnya Proximity (sensor dekat lubang speaker yang bikin layar mati pas HP ditempel ke telinga waktu nelpon) dan Kompas/Magnetometer (buat baca arah utara-selatan).
3.Sensor Lingkungan Environment
Buat baca kondisi sekitar HP. Contoh paling gampang Sensor Cahaya (Light Sensor) (yang kita pakai di aplikasi buat deteksi terang/gelap ruangan) sama Barometer (buat baca tekanan udara atau ketinggian tempat).
